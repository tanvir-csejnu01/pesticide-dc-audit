# Comparative Analysis of All 84 Analytes

## 1. Purpose

This analysis corresponds to the **"Compare all analytes"** step of the project workflow (Figure 1, Tier 4, shwon in student Task-1).

The purpose is to compare all 84 pesticide analytes using the same set of descriptive and statistical criteria before making any later modeling-scope decision.

This analysis is:

- a descriptive data audit;
- an analyte-by-analyte comparison;
- an assessment of data coverage and environmental relationships; and
- evidence to support later modeling decisions.

This analysis is **not**:

- a predictive model;
- a procedure for selecting only a few analytes; or
- a recommendation to exclude any analyte.

All 84 analytes remain in the analysis. Any later restriction or grouping of analytes should be based on explicit evidence from this audit and subsequent modeling requirements.

---

## 2. Input Dataset

The analysis uses:

```text
data/processed/t2_pest_concs_enriched_v2.parquet
```

The dataset contains:

| Item | Value |
|---|---:|
| Chemical-result records | 955,728 |
| Analytes | 84 |
| Monitoring sites | 81 |
| Water years | 2013–2022 |

The dataset is at the **chemical-result level**.

A single sampling activity can contain results for multiple pesticide analytes. Therefore, the number of chemical-result records is much larger than the number of unique sampling activities.

Environmental variables were matched at the sampling-activity level and then joined back to the corresponding chemical-result records.

Thus, multiple analytes measured from the same water sample share the environmental conditions associated with that sampling event, while their pesticide concentrations can differ.

---

## 3. Analysis Script and Outputs

The comparative analysis is generated by:

```text
scripts/11_compare_all_analytes.py
```

The script produces two main output files.

### 3.1 Analyte Summary Table

```text
data/processed/analyte_comparison_full.csv
```

This table contains:

```text
84 rows
```

with one row for each analyte.

It summarizes record counts, sampling activities, spatial and temporal coverage, detections, reporting levels, concentration distributions, environmental matching, and spatial-temporal patterns.

### 3.2 Analyte–Environment Relationship Table

```text
data/processed/analyte_env_relationships.csv
```

This table contains the analyte-specific statistical relationships between pesticide observations and the six environmental variables.

For each analyte and environmental variable, two relationships are considered:

1. environmental variable versus pesticide detection status; and
2. environmental variable versus log10 concentration among detected observations.

Conceptually:

```text
84 analytes
     ×
6 environmental variables
     ×
2 relationship types
     ↓
Analyte–environment relationship tests
```

Some relationships cannot be statistically evaluated when the number of matched observations is below the minimum required sample size. It has a attribute, Spearman's rho, measures how strongly two variables move together in rank order, not their exact values, just whether one tends to go up when the other goes up (or down).

# 4. Common Workflow Applied to All 84 Analytes

The same workflow is applied to every analyte.

This avoids selecting analytes in advance and allows the 84 chemicals to be compared on a common basis.

---

## 4.1 Record Counts and Sampling Activities

For each analyte, the analysis calculates:

- total number of chemical-result records; and
- number of distinct sampling activities (`Activity_ActivityIdentifier`).

These two counts are different because multiple analytes can be measured from the same sampling activity.

For example:

```text
One sampling activity
        │
        ├── Atrazine result
        ├── Simazine result
        ├── Imidacloprid result
        └── other analyte results
```

The environmental conditions belong to the sampling activity, while concentration is measured separately for each analyte.

---

## 4.2 Site and Time Coverage

For each analyte, the analysis determines:

- number of monitoring sites where the analyte was measured;
- water years in which the analyte was measured;
- first observation date; and
- last observation date.

The complete dataset contains 81 analysis sites and covers water years 2013–2022.

Not every analyte was measured at every site or during every part of the study period.

Therefore, spatial and temporal coverage must be evaluated separately for each analyte.

---

## 4.3 Detections, Nondetections, and Reporting Levels

For each analyte, the analysis calculates:

- number of detected observations;
- number of nondetected observations;
- detection rate;
- reporting-level range; and
- reporting-level characteristics before and after January 1, 2018.

The 2018 division is used to examine changes associated with the NWQL laboratory schedule transition from schedule 2437 to 2447.

This is important because a change in analytical reporting limits can affect the observed detection rate.

For example:

```text
Earlier period:
lower reporting limit
        ↓
small concentrations can be detected

Later period:
higher reporting limit
        ↓
some small concentrations may be reported as nondetect
```

Therefore, changes in detection rate over time should not automatically be interpreted as changes in pesticide occurrence.

---

## 4.4 Environmental Matching and Missingness

Environmental-data availability is evaluated separately for each of the six primary environmental variables:

1. discharge;
2. water temperature;
3. dissolved oxygen;
4. pH;
5. specific conductance; and
6. turbidity.

For each analyte, the percentage of records with an available environmental value is calculated separately for each variable.

Environmental completeness is **not represented by a single combined percentage**, because coverage differs substantially among environmental variables.

This is particularly important for turbidity, which has much lower coverage than the other environmental variables.

---

## 4.5 Concentration Distributions

Concentration-distribution statistics are calculated using **detected observations only**.

The analysis includes:

- median concentration;
- interquartile range (IQR);
- maximum concentration; and
- skewness after log10 transformation.

Pesticide concentrations are strongly right-skewed on the original concentration scale.

Conceptually:

```text
Most observations
↓
low concentrations

Small number of observations
↓
very high concentrations
```

Therefore, log10-transformed concentration is also examined:

\[
C_{\log} = \log_{10}(C)
\]

The transformation reduces the influence of extreme high values and makes analyte concentration distributions easier to compare.

The transformation does not mean that the original concentration values are discarded. Original concentrations remain the measured values; the log scale is used for distributional and statistical analysis where appropriate.

---

## 4.6 Spatial and Temporal Patterns

Three main spatial-temporal indicators are evaluated for each analyte.

### Site Detection Coverage

The analysis calculates the percentage of monitored sites where an analyte has at least one detected observation.

This helps distinguish between analytes that are detected broadly across the monitoring network and analytes detected at relatively few sites.

### Seasonal Detection Pattern

Detection rates are compared across seasons to identify the season with the highest observed detection rate for each analyte.

The seasonal categories are based on groups of months, such as:

```text
DJF = December–January–February
MAM = March–April–May
JJA = June–July–August
SON = September–October–November
```

### Yearly Detection-Rate Trend

A simple linear slope is calculated from yearly detection rates.

The resulting variable:

```text
detection_rate_trend_per_year
```

describes the direction and approximate magnitude of change.

A positive value indicates an increasing observed detection rate, while a negative value indicates a decreasing observed detection rate.

This is a **descriptive direction indicator**, not a formal statistical trend test.

---

# 5. Environmental Relationship Analysis

The analysis evaluates whether pesticide observations are statistically associated with environmental conditions.

The six environmental variables are:

```text
Discharge
Water temperature
Dissolved oxygen
pH
Specific conductance
Turbidity
```

Two types of relationships are evaluated.

---

## 5.1 Environmental Variable vs. Detection Status

The first analysis asks:

> Is the environmental condition associated with whether the pesticide was detected or not detected?

Detection status is represented as a binary variable.

For example:

```text
Detected     = 1
Nondetected  = 0
```

The environmental variable is then compared with this detection indicator using Spearman correlation.

---

## 5.2 Environmental Variable vs. Detected Concentration

The second analysis asks:

> Among detected pesticide observations, is the environmental condition associated with pesticide concentration?

Only detected observations are used.

Because pesticide concentrations are strongly right-skewed, concentration is evaluated on the log10 scale.

Conceptually:

```text
Environmental variable
        │
        ▼
Spearman relationship
        │
        ▼
log10(pesticide concentration)
```

---

## 5.3 Why Spearman Correlation Is Used

Spearman correlation is rank-based and does not require a linear relationship between the variables.

The coefficient is represented as:

\[
\rho_s
\]

where:

```text
ρs > 0  → positive association

ρs < 0  → negative association

ρs ≈ 0  → weak or no monotonic association
```

The magnitude indicates the strength of the monotonic relationship.

For example:

```text
ρs = +0.45
```

indicates that higher values of the environmental variable tend to occur with higher detection status or concentration ranks.

However, correlation does **not** demonstrate causation.

---

## 5.4 Minimum Sample Requirement

A relationship is calculated only when at least:

```text
MIN_N_FOR_CORR = 20
```

matched observations are available.

Relationships with fewer than 20 matched observations are not interpreted because the available data are insufficient for the correlation analysis under the current workflow.

---

## 5.5 Multiple-Testing Control

A large number of analyte–environment relationships are evaluated simultaneously.

Therefore, raw p-values alone can produce false-positive findings simply because many statistical tests are performed.

The current analysis uses **False Discovery Rate (FDR) correction** to account for multiple testing.

The adjusted significance measure is reported as:

```text
q-value
```

and statistical significance is evaluated using:

```text
q < 0.05
```

After FDR correction, **726 analyte–environment relationships remain statistically significant at q < 0.05**.

This result indicates that environmental associations are present across a substantial part of the analyte set even after accounting for multiple comparisons.

However, statistical significance should not be interpreted as:

- causation;
- large effect size;
- environmental-variable importance; or
- predictive usefulness.

Large sample sizes can make relatively small associations statistically significant.

Therefore, the correlation coefficient, sample size, environmental coverage, and scientific context should be considered together.

---

# 6. Main Findings Across the 84 Analytes

## 6.1 Record Counts and Coverage

Every analyte contains at least several thousand chemical-result records.

The minimum analyte record count is approximately:

```text
3,928 records
```

Site coverage ranges from approximately:

```text
75 to 81 sites
```

depending on the analyte.

Therefore, some analytes have nearly complete spatial coverage, while others were not measured at every monitoring site.

These differences are partly associated with changes in laboratory analytical schedules and analyte coverage during the study period.

This is a structural characteristic of the dataset and should be considered when comparing analytes or developing later models.

---

## 6.2 Reporting-Level Changes

Among analytes with nondetected observations in both periods, **48 of 84 analytes** show a change in median reporting level before versus after January 1, 2018.

Some changes are substantial.

Examples include:

```text
3-Phenoxybenzoic acid
0.061 → 0.20 µg/L

Acetochlor ESA
0.10 → 0.32 µg/L
```

This means that detection-rate changes across the complete 2013–2022 period cannot always be interpreted independently of analytical sensitivity.

For affected analytes:

```text
Observed detection-rate change
             │
             ├── possible change in pesticide occurrence/use
             │
             └── possible change in laboratory reporting limit
```

These effects have not yet been fully separated.

---

## 6.3 Concentration Distributions

Detected-concentration medians differ substantially among analytes.

The approximate range of analyte medians is:

```text
0.001–0.72 µg/L
```

Raw concentration distributions are strongly right-skewed.

After log10 transformation, the distributions are substantially less skewed.

The average log10-scale skew is approximately:

```text
0.36
```

Therefore, log-transformed concentration provides a more stable basis for later statistical comparisons and concentration modeling than untransformed concentration alone.

---

## 6.4 Spatial and Temporal Patterns

The percentage of monitored sites with at least one detection varies substantially among analytes.

The approximate range is:

```text
52.5%–97.5%
```

Summer (`JJA`) is the most common season associated with the highest observed detection rate.

This pattern is consistent with seasonal differences in pesticide occurrence and use, although the descriptive analysis alone does not establish the cause.

The yearly detection-rate slope ranges approximately from:

```text
−0.037 to +0.070 per year
```

Some analytes therefore show an apparent increase or decrease in observed detection rate over the study period.

However, these slopes have not been separated from changes in analytical reporting limits.

A measured temporal pattern can potentially reflect:

```text
changes in pesticide occurrence/use
             +
changes in environmental conditions
             +
changes in analytical sensitivity
```

Therefore, these slopes should be treated as descriptive indicators rather than formal temporal trends.

---

## 6.5 Environmental Matching

Environmental matching is generally high and stable across analytes for five of the six primary environmental variables.

Approximate matching coverage for the five non-turbidity variables is:

```text
97.6%–99.6%
```

Turbidity has substantially lower coverage:

```text
20.6%–29.9%
```

The lower turbidity coverage is primarily associated with site and time availability of turbidity observations.

Therefore, turbidity-related analyses have considerably fewer matched observations than analyses involving discharge, temperature, dissolved oxygen, pH, or specific conductance.

---

## 6.6 Relationships with Environmental Conditions

The environmental relationship analysis shows that statistically supported associations occur across the analyte set and across multiple environmental variables.

After FDR correction:

```text
726 relationships
```

remain statistically significant at:

```text
q < 0.05
```

This provides evidence that environmental conditions contain measurable statistical relationships with pesticide detection and/or concentration across many analytes.

However, this result should be interpreted carefully.

It does **not** mean:

```text
726 causal relationships
```

and it does not mean that every statistically significant environmental variable will necessarily improve a predictive model.

Instead, the result indicates that environmental information contains statistical signal that warrants further investigation during model development.

The complete analyte-specific results, including:

- environmental variable,
- relationship type,
- sample size,
- Spearman coefficient,
- p-value,
- FDR-adjusted q-value, and
- direction of association

are retained in:

```text
data/processed/analyte_env_relationships.csv
```

# 7. How to Interpret the Comparative Analysis

The purpose of this analysis is not to identify a "best" pesticide analyte.

Instead, it asks whether the 84 analytes have sufficiently comparable data characteristics for later modeling.

The evidence can be organized into four questions.

### Question 1: Is enough pesticide data available?

Evaluate:

```text
record count
+
number of sampling activities
+
site coverage
+
time coverage
```

### Question 2: Is the pesticide frequently detected?

Evaluate:

```text
detection count
+
detection rate
+
reporting-level changes
```

### Question 3: Are environmental predictors available?

Evaluate:

```text
discharge coverage
temperature coverage
DO coverage
pH coverage
conductance coverage
turbidity coverage
```

### Question 4: Is there evidence of environmental association?

Evaluate:

```text
Spearman coefficient
+
sample size
+
FDR-adjusted q-value
+
scientific interpretation
```

These dimensions should be considered together rather than using a single metric to determine analyte suitability.

---

# 8. What the Current Evidence Supports

The current analysis supports continuing the project with a common audit framework for all 84 analytes.

It provides quantitative evidence for:

- analyte-specific sample availability;
- spatial and temporal coverage;
- detection and nondetection patterns;
- reporting-level changes;
- environmental-data availability;
- concentration distributions;
- spatial-temporal patterns; and
- environmental associations.

It also allows analytes with unusual characteristics to be **flagged for further investigation**.

Examples include analytes with:

- low detection rates;
- incomplete site or time coverage;
- substantial reporting-level changes;
- limited environmental matches; or
- insufficient observations for some environmental relationship tests.

Flagging an analyte does not mean excluding it.

---

# 9. What the Current Evidence Does Not Yet Determine

This comparative analysis alone does not determine whether the final modeling strategy should use:

```text
one unified model
        OR
grouped analyte models
        OR
selected analyte-specific models
```

That decision requires consideration of additional information, including:

- analyte coverage during the required Data Companion (DC) period;
- availability and alignment of DC/NHM-PRMS hydrologic predictors;
- treatment of nondetected pesticide observations;
- reporting-level changes;
- differences in analyte behavior and detection frequency; and
- the intended prediction target and model architecture.

Therefore, the current analysis should be treated as **evidence for the later modeling-scope decision**, rather than the modeling-scope decision itself.

---

# 10. Important Limitations

## 10.1 Detection-Rate Trend

The yearly detection-rate trend is based on a simple linear slope across a maximum of approximately 10 water years.

It does not currently include:

- formal trend significance testing;
- seasonal adjustment;
- correction for reporting-level changes; or
- explicit separation of laboratory and environmental effects.

Therefore, it should be interpreted only as a descriptive direction indicator.

---

## 10.2 Correlation Does Not Establish Causation

Spearman correlation identifies monotonic statistical association.

It does not establish that an environmental variable causes a change in pesticide concentration or detection.

For example:

```text
Discharge ↔ pesticide concentration
```

can be influenced by several mechanisms, including:

- dilution;
- runoff transport;
- seasonal pesticide application;
- hydrologic events;
- site characteristics; and
- other unmeasured factors.

The correlation analysis alone cannot distinguish among these mechanisms.

---

## 10.3 Unequal Environmental Coverage

Environmental matching is high for most variables but substantially lower for turbidity.

Therefore, comparisons involving turbidity may be based on fewer sites, sampling activities, and time periods than comparisons involving the other environmental variables.

---

## 10.4 Reporting-Level Changes

Changes in analytical reporting limits can affect observed detection rates.

Consequently, temporal changes in detection should not automatically be interpreted as environmental or pesticide-use trends.

---

## 10.5 Multiple Testing

A large number of statistical relationships are evaluated.

For this reason, the current analysis uses FDR-adjusted q-values rather than relying only on uncorrected p-values.

The primary statistical significance criterion for the current audit is:

```text
q < 0.05
```

Even after correction, statistical significance should be interpreted together with:

- correlation magnitude;
- number of observations;
- environmental-data coverage;
- spatial and temporal coverage; and
- scientific plausibility.

---

# 11. Overall Interpretation

The all-analyte comparison shows that the 84 pesticides differ in their detection frequency, concentration distributions, spatial-temporal coverage, reporting limits, and relationships with environmental conditions.

At the same time, environmental matching is sufficiently extensive for most variables to support broad comparative analysis across the analyte set.

The analysis therefore provides a common evidence base for the next stage of the project without preselecting or excluding analytes.

The next modeling-scope decision should combine this evidence with the required DC/NHM-PRMS coverage, nondetection treatment, reporting-level considerations, and the intended concentration-prediction framework.
